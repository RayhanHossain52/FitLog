# FitLog

FitLog is a modern workout library and planning web application built with Next.js. It allows users to explore workouts, view detailed exercise information, create a daily workout plan, and save workouts for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- REST API

## Key Features

1. **Workout Library**
   - Browse a collection of workouts covering different muscle groups.
   - View workout information such as duration, calories, difficulty, equipment, and rating.

2. **Workout Details**
   - View detailed workout instructions.
   - See targeted muscle groups, equipment, sets, reps, and other workout information.

3. **Daily Workout Plan**
   - Add workouts to today's plan.
   - Track total exercises, workout duration, and estimated calories.

4. **Save Workouts**
   - Save workouts for later.
   - Easily access and remove saved workouts.

5. **Sorting & Responsive Design**
   - Sort workouts by duration, calories, or rating.
   - Fully responsive interface for desktop, tablet, and mobile devices.

## Project Purpose

FitLog was created as a practical Next.js project to practice modern React and Next.js concepts including App Router, Server Components, Client Components, API data fetching, Context API, dynamic routes, responsive design, and TypeScript.
